    Using it in your app

    Add the design system to an ASP.NET, Angular, Java or plain HTML application, theme it and keep it secure.

    Install

    Copy the dist folder into your application. It needs no build tools, packages or internet access. Then load the files in the page layout:

    <html lang="en" data-ds-colour="forest-green">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <link rel="stylesheet" href="/lib/mota-ds/css/mota-ds.min.css">
  <link rel="stylesheet" href="/lib/mota-ds/css/mota-ds-icons.css">
  <!-- your own styles after these -->
</head>
<body>
  <a class="ds-skip-link" href="#main">Skip to main content</a>
  …
  <main id="main" tabindex="-1">…</main>
  …
  <script src="/lib/mota-ds/js/mota-ds.js" defer></script>
</body>
</html>

    Keep the folder structure inside dist: the stylesheets find the fonts and images by relative path (../fonts, ../img).

    ASP.NET Core (MVC and Razor Pages)

    1. Copy dist to wwwroot/lib/mota-ds.
    2. Load the files in Views/Shared/_Layout.cshtml (or Pages/Shared/_Layout.cshtml) with asp-append-version for cache busting.
    3. Move the header and footer from templates/home.html into partial views, for example _Header.cshtml and _Footer.cshtml.
    <link rel="stylesheet" href="~/lib/mota-ds/css/mota-ds.min.css" asp-append-version="true" />
<link rel="stylesheet" href="~/lib/mota-ds/css/mota-ds-icons.css" asp-append-version="true" />
…
<partial name="_Header" />
<main id="main" tabindex="-1" class="ds-main">
  <div class="ds-container">@RenderBody()</div>
</main>
<partial name="_Footer" />
<script src="~/lib/mota-ds/js/mota-ds.js" asp-append-version="true" defer></script>

    Validation messages: give asp-validation-for spans the class ds-field-error, and the summary ds-error-summary. Tag helpers add aria-invalid through the input-validation-error class; map it in your stylesheet:

    .input-validation-error { border-color: var(--ds-error-text); border-width: 2px; }
.field-validation-valid { display: none; }

    ASP.NET Web Forms

    Add the files to Site.Master. Server controls take the classes through CssClass:

    <link rel="stylesheet" href="<%= ResolveUrl("~/lib/mota-ds/css/mota-ds.min.css") %>" />
…
<asp:Label runat="server" AssociatedControlID="txtName" CssClass="ds-label" Text="Full name" />
<asp:TextBox runat="server" ID="txtName" CssClass="ds-input" />
<asp:RequiredFieldValidator runat="server" ControlToValidate="txtName" CssClass="ds-field-error" Display="Dynamic"
     ErrorMessage="Enter your full name" />
<asp:Button runat="server" Text="Submit application" CssClass="ds-btn" />
<asp:GridView runat="server" CssClass="ds-table" GridLines="None" UseAccessibleHeader="true" />

    Content updated by an UpdatePanel keeps working: the script listens on the whole page and sets up new carousels and counters automatically.

    Blazor

    Reference the files in App.razor (or wwwroot/index.html). Write components that output the same markup; the script works with re-rendered content. Call JavaScript only for the helpers:

    await JS.InvokeVoidAsync("MotaDS.toast", "Application saved", new { type = "success" });
await JS.InvokeVoidAsync("MotaDS.openDialog", "confirm-delete");

    Angular

    1. Copy dist to src/assets/mota-ds (or public/mota-ds in newer projects).
    2. Register the styles and the script in angular.json.
    3. Use the classes in component templates. Keep component styles for layout only, and use the tokens (var(--ds-key)).
    "styles": [
  "src/assets/mota-ds/css/mota-ds.min.css",
  "src/assets/mota-ds/css/mota-ds-icons.css",
  "src/styles.scss"
],
"scripts": ["src/assets/mota-ds/js/mota-ds.js"]
    // Use the helpers from a component or service
declare const MotaDS: { toast(message: string, options?: { type?: string }): void; openDialog(id: string): void };

save() {
  this.api.save(this.form.value).subscribe(() => MotaDS.toast('Application saved', { type: 'success' }));
}

    Reactive forms: bind [attr.aria-invalid]="control.invalid && control.touched" on the input and show the message in a <p class="ds-field-error" [id]="…"> linked with aria-describedby. With Angular Material or PrimeNG, load the design system first and set the library's primary colour to var(--ds-key).

    Java (JSP, Thymeleaf), PHP and others

    Serve dist as static files and load it in the common layout as shown under Install. Nothing else is needed.

    Colour theme and customisation

    Set the theme on <html data-ds-colour="…">. To adjust anything else, override tokens in a stylesheet loaded after the design system, never by editing it:

    :root {
  --ds-container-max: 90rem;   /* narrower pages */
  --ds-footer-art: url('/images/our-artwork.webp');
}

    Every message of the script can be translated before it loads:

    <script>
  window.MotaDSConfig = { strings: { showPassword: 'पासवर्ड दिखाएँ', errorSummary: 'कृपया ये त्रुटियाँ ठीक करें' } };
</script>
<script src="/lib/mota-ds/js/mota-ds.js" defer></script>

    Security and hosting

    • Everything is self-hosted: no CDN, web fonts service or analytics. This is a GIGW and CERT-In audit expectation.
    • The script needs no eval and no inline code, so this Content-Security-Policy works: default-src 'self'; img-src 'self' data:; style-src 'self'; font-src 'self'; script-src 'self'. (Templates use a few inline style attributes for examples; move them to your stylesheet.)
    • Preferences (theme, text size, collapsed sidebar) are stored only in the user's browser, never sent to a server.
    • Serve dist with long cache lifetimes and change the file name or add a version query on every release.

    Script reference

    Data attributes and functions of mota-ds.js
    Attribute or functionWhat it does
    data-ds-popover, data-ds-megamenuOn a button with aria-controls: opens and closes the panel; Esc and clicks outside close it.
    data-ds-open="id", data-ds-closeOpen a <dialog> (dialogs and drawers); close the dialog the button is in.
    role="tablist"ARIA tabs with arrow-key, Home and End support.
    data-ds-validateOn a form: validates on submit, writes errors and the error summary.
    data-ds-counterOn a textarea with maxlength: characters left.
    data-ds-password-toggleShow or hide a password.
    data-ds-strength-for="id"Password strength meter for the input with that id.
    data-ds-sortableOn a table: .ds-sort buttons sort the rows.
    data-ds-carousel, data-ds-ticker-toggleBanner carousel; pause button of the ticker.
    data-ds-a11y="…", data-ds-colour-option="…"Accessibility panel options; colour theme choice.
    data-ds-app-toggle, data-ds-app-closeCollapse the application sidebar (desktop) or open and close it (phones).
    data-ds-search-shortcutCtrl K or / focuses this search box.
    <body data-ds-external-notice>Shows a notice before opening links to other websites.
    MotaDS.toast(message, options)Shows a toast. Options: type (success, error, warning), timeout in ms (0 keeps it), action and onAction.
    MotaDS.openDialog(id), closeDialog(id)Open or close a dialog from code.
    MotaDS.validate(form)Validates a form from code; returns true when valid.
    MotaDS.setColour(name), MotaDS.init(root)Change the theme; set up components inside an element (rarely needed).
