    Foundations

    Colour, type, spacing, shape, layout and icons: the tokens every component is built from.

    Colour themes

    DBIM v3.0 defines six primary colour groups. A website uses one group throughout; the Ministry's portal uses Forest Green. Set the group once on the <html> element and every component follows. Select a theme below to preview this documentation in it.

    <html lang="en" data-ds-colour="forest-green">   <!-- forest-green | classic-blue | midnight-purple | burgundy | chrome-yellow | cinnamon-red -->

    Users can also choose a theme from the header (the colour theme control). Their choice is kept in the browser. To fix the theme for an application, leave that control out of the header.

    Key colour and shades

    Values update with the theme you select. Use tokens, never the hex values, so pages follow the theme.

    • Aa
      Key colour--ds-key ·
      Headings, links, primary buttons, icons, the footer
    • Aa
      Shade 2--ds-key-2 ·
      Scroll rails, borders; never behind text
    • Aa
      Shade 3--ds-key-3 ·
      Decorative fills, persona circles
    • Aa
      Shade 4--ds-key-4 ·
      Soft buttons, link cards, table headers
    • Aa
      Shade 5--ds-key-5 ·
      Light bands, hover, selected rows
    • Aa
      Tint--ds-tint ·
      Icon wells, menu hover

    Do

    • Use --ds-key for text and icons on white or on shades 4 and 5: at least 4.5:1 in every theme.
    • Use white text on --ds-key only.

    Don't

    • Put text on shades 2 or 3 except --ds-key-ink.
    • Introduce new brand colours, gradients or tints outside the tokens.

    Noto Sans for every script (DBIM §4.1), self-hosted in dist/fonts. One family covers English, Hindi and Marathi; Odia uses Noto Sans Oriya. Allura is used only for the footer tagline.

    Do

    • Left-align body text (DBIM §4.1.1).
    • Keep line length near 70 characters with .ds-prose.
    • Use one H1 per page, then H2 and H3 in order.

    Don't

    • Justify text, set body text below 14px or anything below 12px.
    • Use all capitals for sentences; keep them for short labels.

    Corners and elevation

    DBIM elements (buttons, alerts, tables, segmented tabs) keep sharp 2 to 4px corners. The newer surfaces (cards, panels, menus, search) use 8 to 12px. Shadows mark things that float or can be picked up; most surfaces have none.

    Layout and breakpoints

    Content sits in .ds-container: full width with side margins of about 6% of the screen (16px on phones), up to 1920px. Build rows with .ds-grid, .ds-split, .ds-stack and .ds-cluster.

    Icons

    The DBIM Visual Components Library, line style. Icons are drawn with a CSS mask, so they take the colour of the text around them and follow the theme and the high-contrast mode. Decorative icons get aria-hidden="true"; an icon-only button gets an aria-label.

    <span class="ds-icon ds-i-download" aria-hidden="true"></span>
<span class="ds-icon ds-icon--lg ds-i-schemes" aria-hidden="true"></span>   <!-- --sm 16 · default 20 · --md 24 · --lg 32 · --xl 48 -->

    The core icons are embedded in mota-ds-icons.css. For the full library add mota-ds-icons-all.css, which loads each icon from dist/icons/ when it is used. Select an icon to copy its markup.
