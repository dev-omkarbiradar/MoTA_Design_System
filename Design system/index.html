One look for every Ministry application

The MoTA Design System is the visual language of the Ministry's new website, packaged as plain HTML, CSS and JavaScript. Use it to redesign any web application, whether it is built on ASP.NET, Angular, Java or plain HTML, without adding a framework.

    Principles

    Every decision in the system follows from five commitments.

    • Government identity

      Built on the Digital Brand Identity Manual (DBIM v3.0): the State Emblem, Noto Sans, the six colour groups, DBIM icons and the Template 1 layout.

    • Accessible by default

      Meets WCAG 2.1 AA and GIGW 3.0: contrast, keyboard use, visible focus, screen reader support, text resizing and an accessibility panel.

    • Framework-free

      Class names and data attributes only. Works in Razor, Web Forms, Blazor, Angular, JSP or static HTML, beside Bootstrap or any component library.

    • Multilingual

      Self-hosted Noto Sans for Latin, Devanagari and Odia. Layouts allow for longer Hindi text, and every message in the script can be translated.

    • Secure to host

      No CDN, no inline script required and no external requests, so a strict Content-Security-Policy works as is. Passes security audit checks.

    Quick start

    Copy the dist folder into your application's static files, then add two stylesheets in the <head> and one script before </body>:

    <link rel="stylesheet" href="/lib/mota-ds/css/mota-ds.min.css">
<link rel="stylesheet" href="/lib/mota-ds/css/mota-ds-icons.css">
…
<script src="/lib/mota-ds/js/mota-ds.js" defer></script>

    Then start from a template or build pages from the components. Step-by-step instructions for ASP.NET MVC, Razor Pages, Web Forms, Blazor and Angular are in Using it in your app.

    Previewing on your computer

    Browsers block fonts and icon files on pages opened straight from disk. Run node serve.mjs in this folder and open http://localhost:4300, or open the folder in any web server.

    Page templates

    Complete pages assembled from the components. Open one, view its source and copy the parts you need.

    • Home page

      Header with mega menus, banner, announcements, service tiles, tabs, What's New, documents and footer.

    • Content page

      Page header with section tabs, readable article with table and FAQ, side column.

    • Documents and listings

      Search and filters, document rows with format and size, pagination and a sortable table.

    • Application form

      Stepper, form sections, every field type, upload, captcha with a text alternative, and validation.

    • Sign in

      Branded sign-in card with password toggle, captcha and single sign-on (Parichay).

    • Dashboard and back office

      Collapsible sidebar, top bar, key figures, work queue, chart, details and file movement.

    • Page not found

      Error page with search and links back into the website.

    Versions and changes

    The system follows semantic versioning. Class names, data attributes and token names are the public interface: a minor version adds to them, and only a major version renames or removes anything. Record the version you use (shown in the first line of mota-ds.min.css) in your application's documentation.

    Change the design system here, in one place, then rebuild and copy dist/ to applications. Do not edit the CSS inside an application; put any application-specific styles in a separate stylesheet loaded after it, using the tokens.
